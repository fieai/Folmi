一轮对话，二十个文件。Folmi 把 AI 改的代码和文档摊开给你：先看要紧的，看不懂的让它说人话，一处一处决定留不留。⏎ 收下，⌫ 丢弃，后悔了随时退回。

问题

AI 一轮改几十个文件，
人很难一处处看完。

AI 一分钟改完的东西，人要看半小时。于是要么一行行看到累，要么闭着眼全收，直到某天发现它顺手删了你没注意的东西。

改了几十个文件，从哪看起？

要紧的排在前面。依赖、构建脚本、配置、大段删除先给你看，旁边写着为什么值得先看。

看不懂它为什么这么改。

当场问。选中一段，让它说人话、解释这处改动，回答就出现在改动旁边，不用切走。

收完才发现不对。

每一步都退得回。收下、丢弃都能撤销；AI 的一整轮改动，也能整批退回去。

一个循环

AI 照常写，
你按自己的节奏看。

Folmi 不拦着 AI，也不给它加审批。它写完一轮，你看一轮；没看完的就留着，下次接着看。

  1. AI 改完

    Claude Code、Codex 在终端里改完，Folmi 马上就看到；窗口在后台时发通知。

  2. 一处一处看

    • 空格 看下一处
    • ⏎ 收下
    • ⌫ 丢弃
    • ⌥⌘Z 撤销刚才那步

  3. 拿不准就问

    让 AI 解释这处改动，或者写一句意见，直接送回给它去改。

  4. 收好，交出去

    收下的就是这次要交的。说明在你看的时候已经写好，一键提交、推送。

  • ⌫丢弃这一处。丢掉的也能拿回来。
  • ⌘Z后悔了？撤销刚才那一步。

功能

看改动时最常用的几样

接住 AI 的每一轮

AI 每说完一轮话，改动单独成一批：能整批退回，也能只看它这一轮改了什么。危险命令在执行前就拦下。支持 Claude Code 和 Codex。

AI 正在改 3 个文件
↺ 整批退回 第 12 轮 · 5 处
只看这一轮
⛔ 已拦下 rm -rf build/*

看过的不用再看

看到哪里记到哪里，像邮件的已读。AI 再改一轮，只有它新动过的那几处会重新出现。

这处改动牵连到哪

AI 改了一个函数，改动上方就写出它被几处调用；删掉或改了名，旧名字还有谁在用；参数改了，哪几处调用没跟着改。按 ⌃⌥H 看一个函数谁调用它、它又调用了谁，能顺着 import 别名、路径别名、再导出找过去。支持 JS、TS 和 Python。

影响 loadInvoice 被 3 处调用
✗ getOrder 改名为 loadOrder，旧名字还有 2 处在调用
✗ 参数 (id) → (id, currency)，2 处没跟着改
⌃⌥H 上下游 · 关系图

意见直接发回给 AI

在改动上写一句「这里别这么做」，一键送回给 agent 去改，带着文件和行号，不用复制粘贴。

终端就在旁边

Claude Code、Codex 在内嵌终端里跑，可以开多个标签。⌘ 点按输出里的 路径:行号，直接跳到那个文件。

打开和切换都很快

原生 macOS 应用，不用 Electron。打开就是上次的样子，十万行的改动也顺着滚。变慢的改动不合入。

待办按日期排好

按 ⌘⇧T 打开待办页：所有项目随手记里的 - [ ] 按过期、今天、这周分组，旁边是月历。日期照 Obsidian Tasks 的写法写在那一行里，比如 📅 2026-10-30。

想到什么，随手记下

在任何 App 里按 ⌃⌥F11，弹出一个小编辑框，写完按 Esc 就收起，边写边保存。每条想法是项目里 ideas/ 下的一个 Markdown 文件，攒够了直接交给 AI 去做。多人项目可以勾「只留在本机」，不会提交给同事。

对比

和 Cursor、VS Code 有什么不同

Cursor 和 VS Code 是用来写代码的编辑器；Folmi 是用来看 AI 改了什么、决定留不留的。三者可以一起开，不用二选一。

Git

常用的 Git 操作也都有

不用再开别的 Git 客户端。Folmi 底下就是 Git：你在终端里敲 git 命令，Folmi 里看到的是同一份状态。

  • 按行暂存
  • 提交和推送
  • 拉取，处理冲突
  • 切换和新建分支
  • 历史和提交图
  • 撤销提交、挑选提交
  • 改提交说明
  • 暂放改动（stash）
  • 管理远端
  • 大仓库模式
我们不做的

不做的事

不替你写代码

写代码交给你喜欢的 AI。Folmi 只管一件事：让你看明白它写了什么。

不给 AI 加审批

AI 照常写，不用等你点头。你看你的，没看完的一直留着。

不是又一个编辑器

没有插件市场、没有一堆面板。能改，但它首先是用来看的。

新增

  • AI 一轮改完时检查调用（JS、TS、Python）：这一轮删掉或改名的函数，别的文件里还有地方用旧名字调用；或者改了函数的参数，有调用没跟着改，Folmi 会在 Claude Code / Codex 结束这一轮前把这些地方列给它，让它先改好。按这一轮动手之前的文件比较，原来就有的问题不算；只算能确定的调用，按方法名猜的不算。每一轮最多拦一次，AI 觉得是有意的可以说明原因不改。在「接入 agent」里打开「一轮改完时检查调用关系」（默认打开），已经接入的项目点「重新安装」或「更新 Codex 钩子」后生效。
v0.11.02026-10-27最新

新增

  • 文件目录里可以新建文件：点筛选框旁边的按钮或在目录空白处右键「新建文件…」建在项目根目录；在文件夹上右键「在「文件夹名」里新建文件…」建在这个文件夹里；在文件上右键「在同一个文件夹里新建文件…」。名字里带 / 会顺便建文件夹；重名会提前提示，不会覆盖已有文件。建好后直接在编辑器里打开，⌥⌘Z 可撤销。
  • 文件目录里可以给文件和文件夹改名：右键「重命名…」，或选中后按回车。名字里带 / 会挪到对应的文件夹；重名会提前提示，不会覆盖已有文件。只改磁盘上的文件，不会替你暂存；编辑器里开着的标签跟着换成新名字，有没保存的改动时要先保存。⌥⌘Z 可撤销。
  • 文件目录里可以删除文件和文件夹：右键「删除…」，或选中后按 ⌘⌫。确认后移到废纸篓，⌥⌘Z 可以放回来，也能在废纸篓里找回；编辑器里开着的标签会关掉。
  • 新的「待办」页：顶部切换栏多了「待办」，⌘⇧T 进出，代替原来的「全项目待办」弹窗。默认列出所有项目随手记里的待办；页头的小菜单可以改看这个项目所有 Markdown 里的待办（比如 AI 写的计划）。上面四个数字（没做完的、今天和过期的、这周到期的、这周做完的），点一下只看那一类；下面按过期、今天、这周、以后、没日期分组，也可以按笔记分组。右边是月历：下划线表示那天记过随手记，圆点表示那天要做和做完的；点一天，列出那天写的随手记（点开是阅读视图，别的项目的会先切过去）和那天的待办；把待办拖到某天就改成那天截止。↑↓ 选，空格勾选（做完的再按一次改回没做完），⏎ 打开到那一行（别的项目的会先切过去），D 设日期；勾选或改日期后可以点「撤销」。
  • 待办可以写日期，用 Obsidian Tasks 的写法：📅 2026-10-30 截止、⏳ 2026-10-28 哪天做、✅ 完成日期；在编辑器里输入 / 选「截止日期」或「哪天做」插入今天的日期。也认 - [/] 进行中和 - [-] 不做了。日期就写在那一行里，Folmi 不另存。在待办页勾选随手记里的待办会顺便写上完成日期；其他文件只在已经在用 ✅ 时才写。阅读视图里，进行中的复选框画成半满，不做了的划掉，日期显示成小标签。
  • 可以查看和管理远端：分支菜单最下面的「远端…」（或命令面板搜「远端」）列出每个远端的地址，推送地址不同时分开写，地址里的密码会遮住；可以复制地址、添加新远端（添加后在后台取回一次），也能删除远端。删除只影响本机，服务器上的东西不变，确认时会说明哪些本地分支跟踪着它；⌥⌘Z 能把地址、远端分支记录和跟踪关系全部恢复。
  • 新的「调用关系」：在 JS、TS、Python 文件里把光标放在函数名上，按 ⌃⌥H 或右键「查看调用关系」（⌘K 搜「调用关系」也行），能看到谁调用了它、它又调用了谁。有「上下游」两棵树和「关系图」两种看法，点任何一个函数就以它为中心展开，⌫ 后退，点位置打开到那一行。能跟着别名找：import { a as b }、import * as、barrel 文件的再导出、require、tsconfig 和 vite 的路径别名（如 @/）、const h = foo、Python 的 import … as / from … import … as，以及 this.svc.load()、self.repo.find() 这类能看出类型的成员调用。只按方法名对上的标「可能」。在后台读，不改项目里的文件。
  • 逐个验收里，JS、TS、Python 文件的改动上方多了一行「影响」：这处改动改了哪些函数，每个被几处调用（比如「loadInvoice 被 3 处调用」），只按方法名对上的单独写「几处可能」；鼠标停上去能看到是哪些函数在调用。点一下打开调用关系，以这个函数为中心。只删掉整个函数、路由回调这类没人按名字调用的入口不显示；大仓库模式下不自动算。
  • 「影响」里也写出删掉和改名的函数：「删了 getOrder，旧名字还有 2 处在调用」「getOrder 改名为 loadOrder，旧名字还有 2 处在调用」，标红排在最前；点开列出还在用旧名字的每一处，点一处打开到那一行。按改动前的文件算，能跟着别名和再导出找；已经改成新名字的调用不算。整个删掉的文件也算。一次最多算 20 个文件。
  • 「影响」里也查参数：函数的参数改了，写出「loadInvoice 参数 (id) → (id, currency)，2 处调用没跟着改」，都对得上时写「3 处调用都对得上」；点开列出每一处调用，对不上的写明少了哪个参数、多了几个，或者没有叫这个名字的关键字参数，点一处打开到那一行。只按参数个数和关键字名检查，不看类型；用 ...args、*args 展开传参的看不出，单独写出来。构造函数改了参数，会检查 new Order(…)、Order(…) 这些创建它的地方。

问答

常见问题

支持哪些 AI？

主要配合 Claude Code 和 Codex：每一轮改动单独成批、整批退回、按轮次看、评论发回、规则写进 CLAUDE.md / AGENTS.md。其他 AI，或者你自己改的文件，也都能看、收下、丢弃，只是没有按轮次接入。

我不太会 Git，能用吗？

能。Folmi 底下用 Git 记录每一处改动，但你只需要看、收下、丢弃。收下的就是下一次要提交的内容，提交说明也替你写好了。项目需要先用 Git 管理起来，第一次打开时 Folmi 会检查。

我的代码会被上传吗？

Folmi 自己不上传任何东西。只有你用到解释、说人话、写提交说明这些 AI 功能时，相关内容才会发给你配置的模型，或者本机的 claude；发送前会先检查里面有没有密钥。

「丢弃」了还能找回来吗？

能。每一步收下、丢弃都记着，⌥⌘Z 撤回。AI 的一整轮改动也能整批退回。

打开时提示「无法验证开发者」怎么办？

内测版已使用 Developer ID 签名，尚未完成 Apple 公证。确认下载来源可信且 SHA256 校验一致后，先尝试打开 DMG 或已安装的 Folmi；若被阻止，进入「系统设置 → 隐私与安全」，找到对应提示并选择「仍要打开」。具体步骤见安装说明。
