# 全部终端：跨项目找到和管理后台终端

状态：设计稿（2026-11-18），排在 [terminal-persistence.md](terminal-persistence.md) 的「独立的后台小 App」修复之后。是 [agent-overview.md](agent-overview.md) 第二期「全部项目的会话列表」的第一步。

## 要解决什么

终端持久化之后，终端在退出 Folmi 后继续跑，越积越多（实际使用一天就有十几个）。现在只能：

- 一个个切项目，看终端面板里有什么；
- 「终端」菜单里看到「N 个后台终端不属于任何已打开的项目」，但看不到是哪些、在跑什么，只能整批结束。

用户想知道：**现在开着哪些终端、各在跑什么、哪个在跑开发服务器、哪些是早就没用的空 shell。**

## 入口

不做常驻面板，用的时候打开，和「项目总览」（⌘⇧O）一样是弹出的面板。

- 「终端」菜单 →「全部终端…」，快捷键 ⌥⌘T。
- ⌘K 命令面板里的「全部终端」。
- 终端面板标签栏右侧一个小按钮，显示后台终端总数（只在多于当前项目的标签数时显示，也就是有别处的终端时）。

## 列表

按项目分组，组的顺序跟项目轨一致；不属于任何已打开项目的放最后一组「不属于任何项目」。组内：在跑程序的在前，空闲的在后，各自按创建时间。

每一行：

| 位置 | 内容 | 例子 |
| --- | --- | --- |
| 左 | 项目图标（同项目轨）| |
| 主文字 | 正在跑的程序；没有就写「空闲」 | `pnpm dev`、`claude`、空闲 |
| 次文字 | 标签名 · 当前目录（相对项目根） | 标签 2 · frontend_consultant_react |
| 右 | 状态和时长 | 运行中 · 1 小时 20 分；已退出（退出码 1） |
| 角标 | 前台程序是 `claude` / `codex` 时，画项目轨同款状态角标 | 等你处理 / 改完待验收 |

- 程序名用后台服务已经报告的前台进程名（`foregroundName`）和后台任务名（`backgroundJobName`），和关闭标签时确认框里的写法一致（`TerminalSession.runningProgram`）。要显示完整命令行（`pnpm dev` 而不是 `node`）时，用前台进程的参数（`ServiceScanner.arguments`），截到 60 字。
- 当前目录用 shell 的 pid 查（现在 `currentDirectory` 的做法）。
- 时长按会话的创建时间算；第一期不做「上次输出时间」（要改协议，见「以后」）。

## 操作

| 操作 | 方式 | 说明 |
| --- | --- | --- |
| 跳过去 | 回车、双击 | 切到那个项目，打开终端面板，选中那个标签，焦点放进终端 |
| 结束 | 行尾的 ×、⌘⌫ | 有程序在跑时先问一次（沿用 `confirmTermination` 的文案）；空闲的直接结束 |
| 认领 | 「不属于任何项目」组里的行，右键「放进当前项目」 | 成为当前项目的一个新标签 |
| 结束所有空闲终端 | 列表底部按钮 | 只结束没在跑程序的 shell；按钮上写数量，「结束 6 个空闲终端」；确认一次 |
| 结束所有后台终端 | 列表底部，次要按钮 | 和「终端」菜单里的一样 |

- 搜索框：按项目名、程序名、目录过滤，打开列表时焦点在搜索框，↑↓ 选行。
- 结束是会丢东西的操作，但终端结束后没法恢复，不进撤销栈（和关闭标签一致）；所以有程序在跑时一定先问。

## 数据和刷新

- 数据来自后台服务的 `list`，不改协议。演示仓库和本地后端（持久化关掉、服务不可用）的终端，从 `terminals` 里读，同样列出。
- 打开列表时查一次；列表开着时每 2 秒查一次（本机套接字，一次不到 1 毫秒）；关掉就停。不加任何后台定时器。
- 结束、认领之后立刻重查。

## 和 agent-overview 第二期的关系

第二期的「全部项目的会话列表」要列 ACP 会话、后台终端里的 `claude` / `codex`、钩子里最近活跃的会话。本列表先把「后台终端」这一块做好，数据（每个终端在跑什么、属于哪个项目）留给第二期复用；第二期在这个列表里加 AI 会话，或者把两者合成一个列表，不再另做一个面板。

## 以后（第一期不做）

- 每行显示最后一行输出、「x 分钟前有输出」：需要后台服务记录最后输出时间，协议加字段。
- 在项目总览（⌘⇧O）的每个项目行显示终端数和在跑的程序。
- 按端口显示开发服务器（项目服务 `ServiceScanner` 已经能按项目找到监听端口的进程，可以和终端对上）。

## 测试

- 分组和排序：在跑的在前、不属于项目的在最后。
- 「结束所有空闲终端」只结束空闲的，在跑的不动。
- 跳转后选中的项目和标签正确（FolmiTests 读回界面）。
- 认领后标签出现在当前项目，`terminalSessionIDs` 写进设置。
- 列表关闭后不再查询（计数器或注入的 service 记录调用次数）。
