# 产品方向

更新：2026-10-19（定位）。旧版（0.4 时期的需求表）已过时，见 git 历史。

## 定位

Folmi 解决的问题：**AI 写得太快，人跟不上。** AI 一轮能改几十个文件，人很难一处处看完，于是要么看到累，要么闭眼全收。Folmi 帮人跟上：先看要紧的，看不懂的当场问，一处一处决定留不留，每一步都退得回，并且越用越顺手（AI 照你的习惯改进）。

- 两样主打：一处一处看 AI 改的代码；读和改 AI 写的 Markdown（阅读视图、渲染差异、编辑辅助）。
- 主要配合 **Claude Code 和 Codex**：按轮次接入（成批、整批退回、回放、评论发回、规则写进 CLAUDE.md / AGENTS.md）。其他 AI 改的文件也能看、收、丢，只是不按轮次接入。
- 它有完整的 Git 图形界面功能（暂存、提交推送、拉取冲突、分支、历史、stash），但**不叫「Git 工作台」**，对外不以 Git 为卖点。Git 是底座，不是重点。
- 对外文案用平实的说法，不写口号式的句子。宣传页在 [site/index.html](../site/index.html)。

## 给谁用、怎么用

macOS。大部分改动由终端里的 Claude Code 或 Codex 写，自己主要做三件事：看它改了什么、决定收下还是丢掉、提交推送。Markdown 文档多半也是 AI 写的，以阅读为主，偶尔改几处。

追求的感觉：极致的快、切换优雅、用着顺手愿意天天开（黏性和爽感）。

## 主循环

AI 改完 → 通知 / 顶部胶囊 → 逐个验收（空格看下一处，⏎ 收下，⌫ 丢弃，⌥⌘Z 撤销）→ 提交（说明已在后台写好）→ 推送。

所有新功能先问一句：它让这个循环更快、更放心，还是只是多了一样东西？

## 原则

1. **Git 本身就是状态。** 收下 = 暂存，没处理 = 留在工作区，丢弃 = 撤销得回来的丢弃。不在 Git 之外另建一套「待定 / 退回 / 已收下」的决定状态：两套状态迟早对不上，对不上就是信任问题。「看过」只是阅读进度，不代表同意。
2. **说清楚范围，而不是加流程。** 动作按范围命名（收下这处 / 收下选中的 3 行 / 收下整个文件），提交框写明本次不包含什么，⏎ 永远不提交。用一行字解决的事，不做成一个页面。
3. **阅读优先。** Markdown 默认是阅读视图（WebView，含公式和 Mermaid），编辑用源码模式加编辑辅助（表格 Tab、`/` 菜单、粘贴图片、`[[` 补全）。不做 Typora 式原位排版。
4. **不重造 agent。** 和 Claude Code / Codex 的对话留在它们自己那里；App 只负责把东西顺手送过去（评论、选区、⌘L 问 AI、说人话），以及接住它的结果（钩子、整批撤回、回放）。
5. **快是硬指标。** 性能门槛在 `scripts/perf-budget.tsv`，`check.sh` 每次都跑；改动前后 A/B 对比，不凭感觉。

## 现在有什么

- Git：改动列表（暂存区 / 工作区两组）、按行暂存、自绘差异画布、全部改动 / 逐个验收、审查评论、提交前检查、预生成提交说明、提交和推送、历史与提交图（撤销提交 / 挑选提交 / 改说明）、拉取和冲突处理、收起改动、大仓库模式。
- Claude Code：钩子（每轮改动的胶囊、整批撤回、危险命令拦截）、回放每一轮、改完通知（不在 Dock 上显示角标）。Codex：MCP 和 AI 标签里的对话已有，按轮次的钩子还没接（另开会话在做）。
- 越用越顺手：反复丢弃的改动和丢弃原因归纳成规则提议，同意后写进 CLAUDE.md / AGENTS.md，「记住了什么」里可查可删；收工卡片记每天验收、撤回、提交的数量和连续天数。
- Markdown：阅读视图、源码编辑辅助、大纲、文档历史。
- 其他：内嵌多标签终端、⌘K、⌘P、全文搜索、多项目、四套主题、启动缓存。

## 不做 / 暂不做

| 项 | 结论 | 理由 |
| --- | --- | --- |
| 逐个验收方案 P1（[review-flow-optimization-v0.6.md](design/review-flow-optimization-v0.6.md)）：待定队列、五种处理决定、跨重启续验、独立提交汇总页、冻结队列 | 不采纳 | 和原则 1 冲突：在 Git 之外再建一套状态。一个人验收 Claude 的改动，没处理的留在工作区就是「待定」，暂存区就是「本次提交」。从中只取了两点：提交框写明不包含哪些改动；当前处滚出视野时显示「回到当前处」，此时 ⏎ / ⌫ 只滚回去不执行 |
| 方案 P3：操作历史抽屉、按批次回看 | 暂不做 | 回放和整批撤回已覆盖主要需要，等用出缺口再说 |
| 实时所见即所得 Markdown | 不做 | 以阅读为主，阅读视图 + 源码编辑已够；代码已在 56eea40 删除，需要时从父提交找回 |
| tree-sitter | 暂不做 | +8 MB，现有词法高亮够看改动；要加更多语言时再接 |
| 脚注 | 遇到再加 | Claude 写的文档很少用 |
| AI 对话框 | 排在最后 | 对话框里聊的就是 agent 本身（Claude Code / Codex 会话，经 ACP 接进终端卡片的 AI 标签），不另起一个模型；之前先做模型配置、MCP、规则提议。见 [ai-roadmap.md](design/ai-roadmap.md) |
| LSP、格式化器、插件平台 | 不做 | 这不是 IDE |
